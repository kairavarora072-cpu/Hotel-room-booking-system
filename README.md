# Hotel Room Booking System — DBMS Mini Project

A relational database mini project built with MySQL 8.0+ to manage guests, rooms, bookings and payments.

## Features
- Guest and room records with primary/unique keys
- Booking records linked by foreign keys
- Date and price validation using CHECK constraints
- Payment tracking and revenue reporting
- JOIN, aggregate, subquery, view and transaction examples

## Requirements
- MySQL Server 8.0 or later
- MySQL Workbench or command-line client

## Run
1. Open `hotel_booking.sql` in MySQL Workbench.
2. Execute the script from top to bottom.
3. Run individual SELECT queries to inspect outputs.
4. Screenshots of representative outputs are in `screenshots/`.

## Important note
The sample data is fictional and intended only for demonstration. This is an academic prototype; it does not include a web interface, authentication, or live room-availability locking.
